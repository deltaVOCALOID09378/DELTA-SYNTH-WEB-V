Thai RVC Web UI

Tone-Preserving Thai RVC System · ระบบแปลงเสียงวรรณยุกต์ไทยแท้

WebUI แปลงเสียงด้วย Retrieval-based Voice Conversion (RVC) ที่ปรับแต่งสถาปัตยกรรมเพื่อรักษาวรรณยุกต์ไทย 5 เสียงครบถ้วน ด้วย RMVPE F0 contour และ Thai ContentVec/HuBERT (ความแม่นยำวรรณยุกต์ ≥ 95%, MOS ≥ 4.0, RTF ≤ 0.3) พร้อมคู่มือสองภาษาไทย/อังกฤษ

  • ครบวงจรในหน้าเดียว: แปลงเสียง (Inference), จัดการ Dataset, ฝึกโมเดล (Train), สร้าง Index (FAISS) และแยกเสียงร้อง/ดนตรีด้วย UVR5
  • รองรับฮาร์ดแวร์หลากหลาย: NVIDIA CUDA, AMD / Intel (DirectML) และ CPU เปิดรันผ่าน Program.py (พอร์ต 9378) หรือ go-web.bat (พอร์ต 7897)
  • โหมดเสียงสด & ปลั๊กอิน DAW: รองรับ realtime_gui.py แปลงเสียงสดความหน่วงต่ำ และรองรับ RVCRealtimeVST สำหรับโปรแกรมทำเพลง
  • ระบบประมวลผล Batch ปลอดภัย: แยก subprocess ลดปัญหา VRAM รั่ว มี clear_vram_safe() พร้อมระบบตรวจซ่อม dependency อัตโนมัติ

The Darkside UI — AI Agent

Local Agentic AI Desktop · Made by DELTA SYNTH

แอปเดสก์ท็อป Windows สำหรับสั่งงาน AI Agent บนเครื่องของคุณเองผ่าน Ollama 100% ไม่ต้องใช้ API Key ภายนอก และจำกัดสิทธิ์การเข้าถึงไฟล์เฉพาะ Workspace ที่กำหนดเท่านั้น

  • หน้าจอ Avalonia / .NET สไตล์โมเดิร์น: เลือกโมเดล สตรีมความคิดและสถานะการทำงานของ Agent แบบสดด้วย NDJSON พร้อมปุ่มยกเลิกทันที
  • เครื่องมือไฟล์ความปลอดภัยสูง: read_file, write_file, list_directory ป้องกัน Path Traversal เขียนไฟล์แบบ Atomic และจำกัดขนาด
  • ความปลอดภัยแบบปิด: Backend และ Gateway ผูกที่ 127.0.0.1 เท่านั้น ควบคุม Concurrency และจำกัดจำนวนเซสชันพร้อมกัน
  • ระบบ Supervisor และการควบคุม: ตรวจสุขภาพโปรเซสอัตโนมัติ มีสคริปต์ setup, start, stop, verify พร้อมใช้งานสมบูรณ์
