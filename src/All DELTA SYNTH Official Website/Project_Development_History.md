# สรุปประวัติการพัฒนาระบบเว็บไซต์ DELTA SYNTH Studio
**Date / เวลาบันทึก:** 22 June 2026
**Project:** ปรับปรุงโครงสร้างหน้าเว็บนักร้อง (Voicebank Hub & Singer Profile Pages)

---

## 1. จุดประสงค์ของโปรเจกต์ (Project Objectives)
- ปรับปรุงการใช้งานเว็บไซต์ให้มีการประสานงาน เชื่อมต่อ และเข้าถึงหน้าต่างๆ ได้ง่ายขึ้น
- เปลี่ยนจากเดิมที่หน้าเว็บมีปุ่ม "Thai VCCV" หรือปุ่มดาวน์โหลดเรียงกันในหน้าเดียว ให้กลายเป็นปุ่ม **"รายละเอียด"**
- สร้างหน้าเพจส่วนตัว (Profile Page) แบบแยกย่อยให้กับนักร้องแต่ละคน (รวมทั้งหมดประมาณ 32 คน)
- ตกแต่งหน้าเพจย่อยของแต่ละคนให้มีสีสันและสไตล์ที่เข้ากับคาแรกเตอร์และไลฟ์สไตล์ (Lifestyle) ของนักร้องคนนั้นๆ
- สร้างปุ่มดาวน์โหลดไฟล์คลังเสียง (Voicebank) แบบแยกรายบุคคล พร้อมนำลิงก์ดาวน์โหลดจริงจาก Google Drive เดิมมาใส่ให้ใช้งานได้ทันที

---

## 2. ลำดับเหตุการณ์และการทำงาน (Action History)

### Phase 1: วางโครงสร้างและสร้างสคริปต์อัตโนมัติ
- วิเคราะห์ไฟล์ต้นฉบับ `3._All Voicebank _ DELTA SYNTH.html` และไฟล์ Collab 
- สร้างสคริปต์ Python (`extract.py`) เพื่อทำหน้าที่ดึงข้อมูลนักร้อง (รายชื่อ, อายุ, เพศ, แนวเพลง, ผู้ให้เสียง) จากไฟล์ HTML เดิมแบบอัตโนมัติ
- สร้างระบบ **Dynamic Theme Generator** ใน Python ที่ทำการแปลงชื่อของนักร้อง (Hash) เพื่อสุ่มกำหนดโทนสี (สีพื้นหลัง, สีตัวอักษร, กรอบข้อความ) ให้มีความเป็นเอกลักษณ์ ไม่ซ้ำกันในแต่ละคน

### Phase 2: สร้างหน้าเพจนักร้องและการเชื่อมโยง (Singer Pages & Navigation)
- รันสคริปต์เพื่อสร้างไฟล์ HTML จำนวน 32 ไฟล์ เก็บไว้ในแฟ้ม `src/singers/`
- ปรับปรุงไฟล์ `src/voicebank.html` และ `src/collab.html` โดยเปลี่ยนปุ่มดาวน์โหลดเดิมเป็นปุ่ม **"รายละเอียด"** สีน้ำเงินที่เมื่อคลิกจะลิงก์เข้าไปยังเพจของคนๆ นั้น
- หน้าโปรไฟล์ย่อยแต่ละหน้าประกอบไปด้วย:
  1. รูปภาพนักร้อง
  2. ข้อมูลพื้นฐาน (Voicer, Release Date, Age & Gender, Genre)
  3. ประวัติและโปรเจกต์ (Biography & Projects)
  4. ตัวอย่างเสียงร้อง (Vocal Samples)
  5. ส่วนสำหรับดาวน์โหลด (Voicebank Downloads)

### Phase 3: การสร้างศูนย์รวมและการเชื่อมโยงแบบรวมศูนย์ (Centralized Hub)
- อัปเดตหน้าแรก `src/index.html` โดยเพิ่มปุ่มขนาดใหญ่ **"เข้าสู่หน้ารวมนักร้อง (Enter Voicebank Hub)"** ในหน้า Hero Section 
- ซ่อมแซมระบบแถบนำทาง (Navbar) ด้านบน ให้ปุ่ม `Voicebanks` และ `Collab` สามารถคลิกเพื่อลิงก์ไปยังหน้าศูนย์รวมได้จากทุกๆ หน้าบนเว็บไซต์
- ทำการรัน `extract.py` อีกครั้งเพื่อให้หน้าย่อยทั้ง 32 หน้าได้รับการอัปเดตแถบนำทางชุดใหม่นี้

### Phase 4: การดึงลิงก์ดาวน์โหลดจริงเข้าสู่ระบบ (Extracting Actual Drive Links)
- ปรับปรุงระบบใน `extract.py` เพื่อให้สคริปต์สามารถสแกนค้นหาปุ่ม `<a href="...">` เดิมในไฟล์ HTML ออริจินัล
- ทำการดึงลิงก์ Google Drive (เช่น `https://drive.google.com/file/d/...`) และชื่อปุ่ม (เช่น *Japanese VCV*, *Thai VCCV*) ของนักร้องแต่ละคนออกมา
- นำลิงก์ที่ดึงมาได้ ไปประกอบร่างเป็นปุ่มดาวน์โหลดจริง (Functional Download Buttons) ลงในหน้าโปรไฟล์ย่อยของนักร้องแต่ละคน
- เมื่อเสร็จสิ้น นักร้องทุกคนจะมีปุ่มดาวน์โหลดไฟล์เสียงของตัวเองที่คลิกแล้วโหลดไฟล์จาก Google Drive ได้ทันที

## 3. ไฟล์หลักที่ถูกสร้างและแก้ไข (Modified Files)
1. **`extract.py`** : หัวใจหลักของโปรเจกต์ (Generator script) ใช้รันเพื่อสร้างหน้าเว็บทั้งหมด
2. **`src/index.html`** : อัปเดต Navbar และเพิ่มปุ่มทางเข้า Hub
3. **`src/voicebank.html`** & **`src/collab.html`** : หน้าศูนย์รวมที่มีการจัดเรียงการ์ดรูปภาพนักร้อง และปุ่ม "รายละเอียด"
4. **`src/singers/*.html`** : ไฟล์หน้าโปรไฟล์ส่วนตัวของนักร้องและแขกรับเชิญทั้ง 32 คน
5. **`src/assets/images/...`** : โฟลเดอร์จัดเก็บรูปภาพของนักร้องที่ถูกดึงมาเพื่อใช้งานในหน้าเพจ

---

## 4. วิธีการทำงานในอนาคต (Future Operations)
- หากมีการเปลี่ยนข้อมูลใน `index.html` (เช่น การแก้ Navbar หรือ Footer) หรือต้องการเพิ่มนักร้องใหม่ ให้ทำการแก้รายชื่อในไฟล์ `extract.py`
- จากนั้นรันคำสั่ง `python extract.py` ใน Terminal สคริปต์จะทำการสร้างและอัปเดตหน้าเว็บทุกหน้าให้ใหม่ทั้งหมดโดยอัตโนมัติ
