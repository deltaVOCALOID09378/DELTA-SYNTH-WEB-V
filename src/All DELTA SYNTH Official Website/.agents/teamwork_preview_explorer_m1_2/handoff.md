# Handoff Report: M1_Setup_Content Analysis

## 1. Observation
- The project root contains 6 main HTML files (e.g., `1._Main _ DELTA SYNTH.html`, `2._About US _ DELTA SYNTH.html`) generated by Wix.
- These HTML files are highly minified, heavily reliant on complex div structures (e.g., `.wixui-rich-text__text`, `.wixui-image`), inline styles, and embedded script bundles.
- The corresponding `*_files` directories contain resized, web-optimized images, as well as Wix JS/CSS bundles.
- The `Picture File` directory contains raw, high-resolution original images of characters, categorized cleanly into `A Full Body Picture` and `A Profile for Singer Picture`.
- `SCOPE.md` outlines `SubM1_Extract` (text/image extraction) and `SubM1_Structure` (creating `/src`, `package.json`, and basic `css/styles.css` with Tailwind config).

## 2. Logic Chain
- **Extraction Strategy**: Due to the deeply nested and minified nature of the Wix DOM, writing a generic automated text scraper using `cheerio` might yield fragmented or garbage text. Since there are only 6 pages, a **manual extraction** (opening files in a browser and copying text into Markdown or JSON) is more reliable and faster for the worker. For images, a script to copy everything from `Picture File` (and selectively from `*_files` for backgrounds) to `/assets/images` is optimal.
- **Directory Setup**: The project requires a strict separation of source (`/src`) and static assets (`/assets`). The worker must initialize these folders manually or via a setup script.
- **Local Server**: A Node-based local server is requested. `npm init -y` followed by `npm install serve -D` is the standard, lightweight approach to serve the project root or `/src` directory.
- **Tailwind Integration**: To allow rapid modern styling without a complex build toolchain initially, the Tailwind CDN (`<script src="https://cdn.tailwindcss.com"></script>`) is the best approach for the HTML files. `src/css/styles.css` can be used for global overrides, custom fonts, and root variables.

## 3. Caveats
- Relying on manual text extraction requires the worker to be thorough and careful to capture all relevant copy from the existing pages.
- Some specific background images or icons might only exist in the `*_files` directories, so the worker cannot solely rely on the `Picture File` folder for all image assets.
- Using Tailwind via CDN means `@apply` directives won't work in the external `styles.css` without a build step. The worker should use standard utility classes directly in the HTML or configure a Tailwind CLI build process if `@apply` is strictly needed.

## 4. Conclusion
I recommend the worker execute the following specific strategy:
1. **Extraction**:
   - **Images**: Run a file copy command to move all `.png` and `.jpg` files from `Picture File` into `/assets/images/`. Review `*_files` directories manually to copy any missing background assets.
   - **Text**: Manually extract the text from the 6 HTML files by opening them in a local browser. Save the text cleanly into `/assets/data/content.json` or individual markdown files.
2. **Setup Structure**:
   - Run `mkdir src src/css src/js assets assets/images assets/data` (or equivalent in PowerShell).
   - Create placeholder HTML files in `/src`: `index.html`, `about.html`, `voicebank.html`, `files.html`, `collab.html`, `events.html`.
3. **Local Dev Server**:
   - Run `npm init -y`.
   - Run `npm install serve --save-dev`.
   - Update `package.json` with the script: `"start": "serve ."`.
4. **Tailwind & CSS**:
   - Create `/src/css/styles.css` containing global CSS variables and font imports.
   - In each HTML placeholder, include `<link rel="stylesheet" href="css/styles.css">` and `<script src="https://cdn.tailwindcss.com"></script>`.

## 5. Verification Method
1. **Directory Check**: Ensure `/src`, `/assets/images`, and `/assets/data` exist and are populated.
2. **Server Check**: Run `npm start` (or `npx serve .`) and verify that the development server starts successfully on port 3000.
3. **Tailwind Check**: Add a test utility class like `bg-red-500` to the `<body>` of `src/index.html`. Navigate to `http://localhost:3000/src/index.html` in a browser to confirm the background turns red.
4. **Content Check**: Verify that `/assets/data` contains the readable, raw textual content from the original HTML files.
